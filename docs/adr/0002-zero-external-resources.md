# 維持零外部依賴的自包含 HTML 架構

儀表板產出單一自包含 HTML 檔案，可離線／file:// 直接開啟。UI 改版新增工具來源色塊、退而標題與失效路徑警告、深色模式等視覺元素時，考慮過引入 CDN 字體或圖示庫以取得更豐富的視覺效果，但最終決定全部以純 CSS／Unicode 字元／`prefers-color-scheme` 綔在 HTML 內實作，不引入任何外部資源。理由：避免 CDN 延遲或斷網時儀表板打不開，且與專案一貫的零 npm 依賴、單檔部署原則一致。

## Consequences

未來若有人建議「直接用 Tailwind／Font Awesome 比較好維護」，這是已經權衡過、刻意捨棄的選項，除非離線可用性的需求本身改變。
