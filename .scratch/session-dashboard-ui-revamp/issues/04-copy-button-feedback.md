# 04 — 複製接續指令按鈕回饋

**What to build:** 使用者點擊「複製接續指令」按鈕後，能立即得到明確的視覺回饋，確定指令真的複製成功，而不是靜默地不知道有沒有生效。

**Blocked by:** None — can start immediately

- [x] 點擊複製按鈕、`navigator.clipboard.writeText` 執行後，按鈕文字暫時變成「已複製✓」
- [x] 1~2 秒後按鈕文字自動恢復成原本的「複製接續指令」（實作為 1500ms，測試以真實 `setTimeout` 等待驗證）
- [x] 不引入新的 DOM 元素（例如 toast、彈出通知），只改按鈕自身文字
- [x] 連續快速點擊同一顆按鈕（或短時間內再點一次）不會造成文字卡在「已複製✓」回不去，或計時器互相干擾（每次點擊先 `clearTimeout` 舊計時器再重新排定，測試驗證舊計時器不會提前觸發、且最終仍正常恢復）
- [x] 透過既有的 DOM 執行測試手法驗證點擊後按鈕文字確實變化（本次不只驗證即時狀態，也用真實 `setTimeout` 實際等待驗證了恢復行為）
- [ ] 部署後在真實瀏覽器上肉眼確認：點擊複製按鈕後看到「已複製✓」，稍後恢復原文字，且剪貼簿內容確實是預期的接續指令 —— 未勾選：本次仍維持 `--quiet` 不開瀏覽器操作真實資料，按鈕文字變化與計時器行為已透過 `node:vm` 執行內嵌前端 script 驗證，但實際瀏覽器視覺呈現與剪貼簿寫入結果需要使用者或下次工作階段人工確認
