# 04 — 複製接續指令按鈕回饋

**What to build:** 使用者點擊「複製接續指令」按鈕後，能立即得到明確的視覺回饋，確定指令真的複製成功，而不是靜默地不知道有沒有生效。

**Blocked by:** None — can start immediately

- [ ] 點擊複製按鈕、`navigator.clipboard.writeText` 執行後，按鈕文字暫時變成「已複製✓」
- [ ] 1~2 秒後按鈕文字自動恢復成原本的「複製接續指令」
- [ ] 不引入新的 DOM 元素（例如 toast、彈出通知），只改按鈕自身文字
- [ ] 連續快速點擊同一顆按鈕（或短時間內再點一次）不會造成文字卡在「已複製✓」回不去，或計時器互相干擾
- [ ] 透過既有的 DOM 執行測試手法驗證點擊後按鈕文字確實變化（若測試環境無法驗證 `setTimeout` 之後恢復，至少驗證「已複製✓」狀態本身被正確設置）
- [ ] 部署後在真實瀏覽器上肉眼確認：點擊複製按鈕後看到「已複製✓」，稍後恢復原文字，且剪貼簿內容確實是預期的接續指令
