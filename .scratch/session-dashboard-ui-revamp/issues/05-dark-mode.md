# 05 — 深色模式

**What to build:** 使用者在夜間使用儀表板時，畫面自動跟隨系統／瀏覽器的深色模式偏好切換，不需要手動找按鈕切換，也不會太刺眼。

**Blocked by:** None — can start immediately

- [x] 新增 `@media (prefers-color-scheme: dark)` CSS 區塊，涵蓋當時已存在的所有卡片與版面元素（背景、文字顏色、邊框、meta 資訊等）
- [x] 不加入任何手動切換深色/淺色模式的按鈕或 JS 邏輯，純 CSS 跟隨系統偏好
- [x] 深色模式下文字與背景的對比清楚可讀，不是單純把淺色配色反轉導致刺眼或看不清楚（stale-path 警告改用較亮的 `#f87171`、工具徽章改用較亮的 `#f59e0b`／`#60a5fa`、徽章邊框改用白色半透明，皆非單純反轉淺色配色）
- [x] 不引入任何外部資源（字型、圖示庫），純 CSS 實作
- [x] 透過字串檢查確認產出的 HTML 中存在 `@media (prefers-color-scheme: dark)` 區塊
- [ ] 部署後在真實瀏覽器上，將系統或瀏覽器切換成深色模式，肉眼確認儀表板正確切換且可讀 —— 未勾選：此項本質上需要真實瀏覽器並手動切換系統/瀏覽器的深色模式偏好才能驗證，`node:vm` 假 DOM 無法執行 CSS media query，僅能以字串檢查與程式碼審視確認邏輯與配色數值正確，留待使用者或下次工作階段人工確認
