# 05 — 深色模式

**What to build:** 使用者在夜間使用儀表板時，畫面自動跟隨系統／瀏覽器的深色模式偏好切換，不需要手動找按鈕切換，也不會太刺眼。

**Blocked by:** None — can start immediately

- [ ] 新增 `@media (prefers-color-scheme: dark)` CSS 區塊，涵蓋當時已存在的所有卡片與版面元素（背景、文字顏色、邊框、meta 資訊等）
- [ ] 不加入任何手動切換深色/淺色模式的按鈕或 JS 邏輯，純 CSS 跟隨系統偏好
- [ ] 深色模式下文字與背景的對比清楚可讀，不是單純把淺色配色反轉導致刺眼或看不清楚
- [ ] 不引入任何外部資源（字型、圖示庫），純 CSS 實作
- [ ] 透過字串檢查確認產出的 HTML 中存在 `@media (prefers-color-scheme: dark)` 區塊
- [ ] 部署後在真實瀏覽器上，將系統或瀏覽器切換成深色模式，肉眼確認儀表板正確切換且可讀
