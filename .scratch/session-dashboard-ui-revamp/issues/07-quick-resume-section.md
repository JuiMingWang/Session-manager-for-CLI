# 07 — 接續快速區

**What to build:** 使用者一打開儀表板，不用先想到哪個專案，就能在頁面最上方看到全站最近用過、而且確定還能接續的幾筆 session，不管上面搜尋框或篩選條件打了什麼都不受影響。

**Blocked by:** 02（需要 `pathExists` 欄位才能在挑選時排除路徑已失效的 session）

- [ ] 頁面頂部新增一個獨立區塊（接續快速區），不分專案、平面顯示 session 卡片
- [ ] 挑選規則：從全部 session 中排除 `pathExists === false` 者，依 `lastActiveAt` 由新到舊取前 8 筆
- [ ] 這個區塊完全不受搜尋框、分類篩選、工具篩選、時間範圍篩選的狀態影響——不管使用者怎麼搜尋/篩選下方內容，這裡永遠顯示全站最新 8 筆
- [ ] 卡片為精簡型：只顯示專案名稱（`displayName`）、標題、最後互動時間、接續按鈕；不顯示 branch、開始時間、完整路徑
- [ ] 接續按鈕的行為（複製指令的格式與內容）與既有分群卡片一致
- [ ] 透過既有的 DOM 執行測試手法驗證：快速區固定顯示 8 筆、不含 `pathExists === false` 的項目、且在模擬搜尋/篩選狀態變動時內容不變
- [ ] 部署後在真實資料／瀏覽器上肉眼確認：快速區顯示的 8 筆確實是全站最新且都是可接續的（沒有已知失效路徑混入），在搜尋框打字或切換篩選時快速區內容不變
